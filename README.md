# Qustāh · Shindo raws

Files QustahShindo downloads at runtime, and its tests.

| Path | What |
|---|---|
| `rellauto` | Auto Spin RELL Bloodline (queued with queue_on_teleport, so keep this path) |
| `shindo/esp.lua` | The overhead ESP: bar presets, per-player panels and chams, the menu preview with its capsules |
| `shindo/teleports.lua` | Saved teleport spots per map (Player › Teleports › Locations) |
| `tests/` | Mock Roblox, hub / lib / raw tests and the ESP benchmark (see `tests/README.md`) |
